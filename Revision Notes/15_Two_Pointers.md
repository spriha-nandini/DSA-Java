# 👯 Two Pointers

> ⏱ 2 min revision

---

## ✨ Template

```java
int left = 0;
int right = arr.length - 1;

while(left < right){

    if(condition)
        left++;

    else
        right--;
}
```

---

## ⭐ Remember

- Start from both ends
- Move one pointer at a time
- O(n)
