# 🟠 Queue

> ⏱ 2 min revision

---

## ✨ Declaration

```java
Queue<Integer> q = new LinkedList<>();
```

---

## ✨ Functions

| Task | Syntax |
|------|--------|
| Add | `q.offer(x)` |
| Remove | `q.poll()` |
| Front | `q.peek()` |
| Size | `q.size()` |
| Empty | `q.isEmpty()` |
| Clear | `q.clear()` |

---

## ⭐ Remember

- FIFO → First In First Out
- `offer()` → Add
- `poll()` → Remove + Return
- `peek()` → Front element

---

## 🎯 Used In

- Queue Using Two Stacks
- BFS
- Level Order Traversal
