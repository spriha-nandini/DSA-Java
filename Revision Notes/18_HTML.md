# 🌐 HTML

> ⏱ 3 min revision

---

## ✨ Basic Structure

```html
<!DOCTYPE html>
<html>
<head>
    <title>Page</title>
</head>
<body>

</body>
</html>
```

---

## ✨ Common Tags

| Tag | Purpose |
|------|----------|
| `<h1>` | Main heading |
| `<h2>` | Sub heading |
| `<p>` | Paragraph |
| `<br>` | New line |
| `<hr>` | Horizontal line |
| `<strong>` | Bold text |
| `<em>` | Italic text |
| `<img>` | Image |
| `<a>` | Hyperlink |
| `<div>` | Container / Box |
| `<span>` | Inline container |
| `<button>` | Button |
| `<input>` | Input field |

---

## ✨ Image

```html
<img src="cat.jpg" alt="Cat">
```

---

## ✨ Link

```html
<a href="https://google.com">Google</a>
```

---

## ✨ Div

```html
<div class="card">
    <h1>Spriha</h1>
    <p>ECE Student</p>
</div>
```

---

## ⭐ Remember

- `class=""` → Used by CSS
- `id=""` → Unique element (JavaScript)
- `<div>` = Most used container
